 MarioClub Adventure Club

A Mario-themed fan club website built with HTML & CSS. It introduces Mario and his friends with a gallery and contact form.

Live Demo: https://elechigreatness.github.io/Mario-Adventure-Club/

🍄 Pages Inside
Home - "It's Me, Mario!" welcome story from Mushroom Kingdom
Friends - Meet Mario Friends:
- Luigi - Mario's younger brother (green hat)
- Princess Peach - Ruler of Mushroom Kingdom
- Yoshi - Friendly dinosaur
- Toad - Loyal attendant with mushroom head
- Bowser - Dragon-turtle villain

Gallery - Screenshots of Mario game scenes
Contact - Form (Name, Email, Message) + Mario holding question block

🛠️ Built With
- HTML5
- CSS3
- Red/Yellow Mario theme, responsive layout
